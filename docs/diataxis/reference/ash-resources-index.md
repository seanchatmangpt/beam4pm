# Ash resources index (reference)

Index of `BeamPM.Ash.Resources.*` — the Ash resources exposed by
`BeamPM.Ash.Domain` (`lib/beam4pm_ash_domain.ex`, 673 `resource(...)`
registrations). Every file is GENERATED by ggen_igniter from the admitted
`bpm:RecordType` graph (`lib/beam4pm_ash/resources/*.ex`, first line of
each file); one-liners below are the resources' own `@moduledoc` strings.

For the complete per-type surface, use the generated per-record-type pages
(`docs/reference/types/`) and `docs/reference/beam4pm_types_reference.md`.
This page is a curated index of the clusters a newcomer touches first.

## OCEL 2.0 core

- `OcelEvent` — An OCEL 2.0 event: one recorded occurrence in an
  object-centric log. (`lib/beam4pm_ash/resources/ocel_event.ex`)
- `OcelObject` — An OCEL 2.0 object: one entity participating in the
  process. (`ocel_object.ex`)
- `OcelRelationship` — A qualified relationship linking an event or object
  to an object. (`ocel_relationship.ex`)
- `OcelAttribute` — One named, timestamped attribute value on an OCEL
  event or object. (`ocel_attribute.ex`)
- `EventLog` — A named collection of events forming one process-mining
  log. (`event_log.ex`)
- `EventType` — A declared OCEL event type and its attribute schema.
  (`event_type.ex`)
- `ObjectType` — A declared OCEL object type and its attribute schema.
  (`object_type.ex`)

## Discovery and conformance

- `LogTrace` — One case-centric trace: an ordered activity sequence for a
  single case. (`log_trace.ex`)
- `DfgEdge` — One frequency-annotated directly-follows edge between two
  activities. (`dfg_edge.ex`)
- `ConformanceResult` — Conformance-checking metrics computed for one
  trace against a model. (`conformance_result.ex`)
- `ProcessVariant` — one mined process variant.
  (`process_variant.ex`)
- `PetriPlace` / `PetriTransition` / `PetriArc` — Petri net places,
  transitions, and weighted place-transition arcs. (`petri_place.ex`,
  `petri_transition.ex`, `petri_arc.ex`)
- `PowlLeaf`, `PowlSequenceOperator`, `PowlParallelOperator`,
  `PowlChoiceOperator`, `PowlLoopOperator` — the POWL process-model
  language operators. (`powl_*.ex`)
- `PlanningAction` — One PDDL-style planning action with its preconditions
  and effects. (`planning_action.ex`)

## Service telemetry

- `ServiceSpan` — One OpenTelemetry-style tracing span observed for a
  service call. (`service_span.ex`)
- `SpanEdge` — One frequency-annotated service-to-service edge derived
  from tracing spans, tagged with the evidence class that supports it:
  `parent_child_link` (observed) or `temporal_adjacency` (inferred).
  (`span_edge.ex`)

## Governance, receipts, and authority

- `ReceiptSignature` — Admits a cryptographic receipt signature bound to
  an exact paid runtime consequence. (`receipt_signature.ex`)
- `ReceiptRequiredGate` — a gate demanding a receipt.
  (`receipt_required_gate.ex`)
- `PlannerLease` — Grants time-bounded construction authority for one work
  item without DO authority. (`planner_lease.ex`)
- `AuthorityCeiling` — a typed authority ceiling.
  (`authority_ceiling.ex`)
- `EntitlementGrant` — Receiptable grant of a capability to a tenant.
  (`entitlement_grant.ex`)

## Commercial

- `TenantAccount` — Commercial tenant bound to account, region, and
  edition. (`tenant_account.ex`)
- `BillingAccount` — Bill-to account with currency and invoice delivery
  profile. (`billing_account.ex`)
- `UsageEvent` — one metered usage event. (`usage_event.ex`)
- `MeterDefinition` — a meter definition. (`meter_definition.ex`)
- `InvoiceLineItem` — one invoice line. (`invoice_line_item.ex`)
