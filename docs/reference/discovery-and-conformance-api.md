## BeamPM.Discovery

### `traces_from_events/2`

`lib/beam4pm_discovery.ex:42-65`

```elixir
@spec traces_from_events([BeamPM.Types.OcelEvent.t()], String.t()) ::
        [BeamPM.Types.LogTrace.t()]
```

Groups OCEL events into case-centric `LogTrace` structs.

| Aspect | Behavior | Location |
|---|---|---|
| Case id source | `attributes` map, string key `case_attr_key` | line 46 |
| Missing/`nil` attributes | event dropped | lines 46-51 |
| Event ordering within case | `{event_time, event_id}` | line 57 |
| `activity_sequence` | mapped from `event_type` | line 58 |
| Trace ordering | sorted by `case_id` | line 53 |
| Construction | `LogTrace.new/1` | lines 60-63 |

```elixir
events = [
  %BeamPM.Types.OcelEvent{event_id: "e1", event_time: "2026-01-01T10:00:00Z",
    event_type: "submit", attributes: %{"case" => "c1"}},
  %BeamPM.Types.OcelEvent{event_id: "e2", event_time: "2026-01-01T10:05:00Z",
    event_type: "approve", attributes: %{"case" => "c1"}}

BeamPM.Discovery.traces_from_events(events, "case")
# => [%BeamPM.Types.LogTrace{case_id: "c1", activity_sequence: ["submit", "approve"]}]
```

### `dfg_from_traces/1`

`lib/beam4pm_discovery.ex:72-86`

```elixir
@spec dfg_from_traces([BeamPM.Types.LogTrace.t()]) :: [BeamPM.Types.DfgEdge.t()]
```

Flat-maps each trace's `activity_sequence` into adjacent `(a, b)` pairs via the private
`adjacent_pairs/1` (lines 151-156: `Enum.zip(seq, Enum.drop(seq, 1))`), counts frequencies
with `Enum.frequencies/1` (line 76), sorts by `{source, target}` (line 77), and builds
`DfgEdge` structs (lines 78-85).

```elixir
traces = [%BeamPM.Types.LogTrace{case_id: "c1", activity_sequence: ["submit", "approve"]}]
BeamPM.Discovery.dfg_from_traces(traces)
# => [%BeamPM.Types.DfgEdge{source_activity: "submit", target_activity: "approve", frequency: 1}]
```

### `conformance/2`

```elixir

        BeamPM.Types.ConformanceResult.t()
```

Computes fitness and precision of one trace against a `DfgEdge` list.

| Field | Computation | Location |
|---|---|---|
| `fitness` | fraction of trace's adjacent pairs present in the edge set (`MapSet` membership) | lines 134-140 |
| `fitness` (short trace) | `1.0` when trace has fewer than 2 activities | lines 130-131 |
| `precision` | delegated to `BeamPM.Precision.etc_precision/2` — never re-derived locally | line 143 |

## BeamPM.Precision

### `etc_precision/2,3`

`lib/beam4pm_precision.ex:63-97`

```elixir
@spec etc_precision([BeamPM.Types.DfgEdge.t()], BeamPM.Types.LogTrace.t()) :: float()
@spec etc_precision([BeamPM.Types.DfgEdge.t()], BeamPM.Types.LogTrace.t(), float()) :: float()
```

Real ETC (escaping-edges) precision, structurally adapted from ex4pm's
`Ex4pmEngine.ETCPrecision` Petri-net formula (moduledoc, lines 3-50), specialized to a
directly-follows-graph model and a single trace:

```text
Precision_ETC = 1.0 - (total_escaping / (total_enabled + alpha * total_escaping))
```

Mechanics:

| Step | Behavior | Location |
|---|---|---|
| `out_degrees/1` | per-source count of distinct outgoing model edges ("enabled transitions") | lines 101-107 |
| Known model edge (pair `{from, to}` in edge set) | `escaping = max(0, enabled - 1)` (sync move) | lines 75-87 |
| Unknown pair | `escaping = enabled` (pure log move) | lines 75-87 |
| Accumulation | sums `total_enabled`/`total_escaping` across all pairs of the one trace | lines 75-87 |
| `denominator` | `total_enabled + alpha * total_escaping` | line 89 |
| Precision (`denominator > 0`) | `max(0.0, 1.0 - total_escaping / denominator)` | line 92 |
| Precision (`denominator == 0`) | `1.0` | line 94 |
| Short trace (`< 2` activities) | `1.0` by convention, matching `conformance/2`'s fitness convention | lines 67-69 |
| `alpha` default | `0.0` — ex4pm's `:negative_event_weight` smoothing knob, optional 3rd arg | line 64 |

```elixir
edges = [
  %BeamPM.Types.DfgEdge{source_activity: "submit", target_activity: "approve", frequency: 1},
  %BeamPM.Types.DfgEdge{source_activity: "submit", target_activity: "reject", frequency: 1}
]
trace = %BeamPM.Types.LogTrace{case_id: "c1", activity_sequence: ["submit", "approve"]}

BeamPM.Precision.etc_precision(edges, trace)
# pair ("submit","approve"): enabled=2 (two edges out of "submit"), known
#   -> escaping = max(0, 2-1) = 1
# total_enabled=2, total_escaping=1, alpha=0.0 -> denom=2 -> precision = 1.0 - 1/2
# => 0.5

BeamPM.Precision.etc_precision(edges, trace, 1.0)
# alpha=1.0 -> denom = 2 + 1*1 = 3 -> precision = 1.0 - 1/3
# => 0.6667 (approx)
```
