# beam4pm WASM Engine Op Reference

GENERATED by ggen (`beam4pm-wasm-engine-pack`) from the WASM engine ABI graph.
Do not edit. The engine-op counterpart of `beam4pm_types_reference.md`.

Every engine below is a Rust crate compiled to `wasm32-wasip1` and hosted inside
the BEAM by wasmex, behind one shared linear-memory JSON ABI:

```text
<prefix>_alloc(len)     -> ptr
<prefix>_call(ptr, len) -> packed_u64   # (out_ptr << 32) | out_len
<prefix>_dealloc(ptr, len)
```

The engines differ only in that export prefix and in their op catalog.

## Consequence classes

- **READ** — observational: a pure computation or a handle-local query.
- **DO** — mutates state *inside* the engine's own wasm linear memory: mints a
  handle, frees a handle, or edits an in-engine session/graph/OCEL.

Neither class is host authority. Nothing in this catalog reaches the filesystem,
the network, or another process; consequential host actuation stays external,
behind GymAct/BRCE admission.
