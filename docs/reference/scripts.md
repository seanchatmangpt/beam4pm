# BEAM4PM Automation Scripts

Every `scripts/*.sh` regeneration or verification entry point, its one-line purpose, and
what it produces or checks. All scripts are run from the repo root; equivalent `just`/`make`
targets are noted in `CLAUDE.md` for the primary ones (`sync`, `test`, `verify`).

## Gate scripts

| Script | Purpose | Regenerates / checks |
|---|---|---|
| `gate_m2_check.sh` | GATE M2 — deterministic reprojection proof | Deletes every file marked `GENERATED by ggen` under `SEARCH_DIRS` (`src lib test gleam/src gleam/test schema docs/reference infra/gcp/cloudrun infra/gcp/packer .github/workflows`), regenerates, diffs — proves ggen is a pure function of `(ontology.ttl, pack templates)`; an `EXIT` trap backs up and restores the swept files, so a plain `Ctrl-C` is safe but a `SIGKILL` mid-run is not |
| `gate_lint_truth.sh` | GATE LINT-TRUTH — static overclaiming-phrase scanner (transplanted from ex4pm) | Checks hand-authored surfaces (never `GENERATED` files) against the banned-phrase list from `no-overclaiming-rust.md` |
| `gate_authorship_check.sh` | GATE AUTHORSHIP — every unmarked file under a manufactured root is an admitted, counted `bpm:HandAuthoredSource` (VISION-2030 s2/s24) | Diffs the manufactured manifest `schema/beam4pm_hand_authored_source.tsv` against `git ls-files` under `src lib gleam/src gleam/test test schema docs/reference infra/gcp/{cloudrun,packer}`; refuses `REFUSED_UNADMITTED` / `_STALE_ADMISSION` / `_CONTRADICTION` / `_SHA_DRIFT` / `_EXPIRED` / `_MISSCOPED` / `_UNBOUND_DEBT`; `--exercise` runs every acceptance command and refuses failing/vacuous ones unless the declared prerequisite is absent |
| `gate_engine_dispatch_check.sh` | GATE ENGINE DISPATCH — every manufactured native-engine facade op (rendered from `bpm:Engine`/`bpm:EngineOp` facts) is an op its crate actually dispatches | Reads the manufactured manifest `schema/beam4pm_engine_ops.tsv` and greps each engine's `bpm:dispatchSource` for string-literal `"<op>" =>` match arms (alternations split); refuses `REFUSED_OP_NOT_DISPATCHED` / `REFUSED_ENGINE_NOT_DISPATCHED`; reports `UNEXPOSED_DISPATCH_ARM` (scope control) and `DISPATCH_SOURCE_ABSENT` (BLOCKED, e.g. an uninitialised submodule) without refusing |
| `roundtrip_check.sh` | GATE M5 — cross-language identity check | Checks Erlang↔Elixir↔Ash JSON/ETS wire-format round-trip identity for every admitted `bpm:RecordType` (full + minimal variants), three directions: elixir-verifies-erlang, erlang-verifies-elixir, ash-verifies-wire (the Ash leg's identity relation is `DateTime.compare/2 == :eq` for datetime attributes, not byte identity, and its synthetic `:id` primary key is disclosed as Ash-only) |

Regenerates one `Ash.Resource` module **per** admitted `bpm:RecordType` under `lib/beam4pm_ash/resources/<record_name>.ex` (290 files, `--on-stale prune` removes orphans), plus `lib/beam4pm_ash_domain.ex` (the `BeamPM.Ash.Domain` registry) and `lib/beam4pm_ash_roundtrip.ex` (GATE M5's ash-verifies-wire leg) — superseding the former single monolithic `lib/beam4pm_ash.ex` (289 modules in one file), which this script now deletes (`rm -f`) before resyncing so the old and new module definitions never collide in the same compile pass |
| `oracle_check.sh` | GATE W2 — differential dogfood gate for beam4pm discovery | Compares real stdout/file bytes across generated Erlang, Elixir, native rust4pm oracle, and wasm4pm oracle over seeded logs |
| `actuation_sync.sh` | GATE PI7/PI8 (BRCE actuation leg) — `ggen_igniter`-manufactured Reactor actuation pipeline | Regenerates `BeamPM.Actuation` from pack igniter assets + `bpma:AdmittedActuation` ontology facts; uses `qualification/fixtures/toy_gym_bridge.py` |

## Usage notes

- Most sync scripts follow the pattern: read `ontology.ttl` facts for a given namespace
  (e.g. `bpma:AdmittedActuation`), invoke `ggen sync run` or `ggen_igniter`, then diff/verify
  the resulting generated file against expectations.
- Use the matching per-family script rather than a blanket `ggen sync run` when iterating on
  one ontology slice — e.g. `rf1_dfg_sync.sh` alone to touch only `BeamPM.RF1.DfgDiscovery`.
- `gate_m2_check.sh` is destructive to `GENERATED by ggen`-marked files (deletes then
  regenerates) — never run it expecting untracked local edits to those files to survive.
