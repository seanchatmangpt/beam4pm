## 1. Classification (every lib/ + src/ + gleam/ file)

The classifier is GATE AUTHORSHIP's own predicate, applied per root:
a file is **GENERATED** iff its first 3 lines (case-insensitive) carry
`GENERATED by ggen`; otherwise it is **HandAuthoredSource-admitted** iff it
has a row in the manufactured manifest
`schema/beam4pm_hand_authored_source.tsv`; otherwise **unadmitted** (the
gate refuses the tree).

Reproduce the file classification:

```bash
for root in lib src gleam/src gleam/test test; do
  m=0; u=0
  while IFS= read -r f; do
    [ -f "$f" ] || continue
    if head -3 "$f" | grep -qi "GENERATED by ggen"; then m=$((m+1)); else u=$((u+1)); fi
  done < <(git ls-files --cached --others --exclude-standard -- "$root")
  echo "$root GENERATED=$m unmarked=$u"
done
```

## 2. Lines and the 比 number

Reproduce the line split (same roots, same marker predicate):

```bash
total_m=0; total_h=0
for root in lib src gleam/src gleam/test; do
  while IFS= read -r f; do
    [ -f "$f" ] || continue
    n=$(wc -l < "$f" | tr -d ' ')
    if head -3 "$f" | grep -qi "GENERATED by ggen"; then total_m=$((total_m+n))
    else total_h=$((total_h+n)); fi
  done < <(git ls-files --cached --others --exclude-standard -- "$root")

echo "manufactured=$total_m hand=$total_h total=$((total_m+total_h))"
```

ggen marker in its first 3 lines, every hand line has a sha-bound admission
