# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's private
vulnerability reporting for this repository:

https://github.com/seanchatmangpt/beam4pm/security/advisories/new

Do not open a public issue for a security report. Reporting privately lets us
assess, fix, and coordinate disclosure before the details become public.

When reporting, please include, if known:

- A description of the vulnerability and its potential impact.
- Steps to reproduce, or a minimal example.
- The affected version(s), commit SHA, or file(s)/module(s) involved.

## Supported Versions

Security fixes are applied to the latest release on the default branch
(`main`). Older tags are not backported unless otherwise noted.

## Response Process

- We aim to acknowledge new reports within 5 business days.
- We will work with you to understand and validate the issue, and to agree on
  a disclosure timeline.
- Once a fix is available, we will publish a GitHub Security Advisory and
  credit the reporter, unless anonymity is requested.

Thank you for helping keep this project and its users safe.
